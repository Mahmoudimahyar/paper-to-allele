# Implement one task
1. Confirm the feature spec and acceptance command.
2. Add/update the smallest failing test that captures the required behavior.
3. Implement the minimal production code.
4. Run focused tests after each coherent increment.
5. Preserve medical provenance, UNKNOWN states, privacy boundaries, and deterministic behavior.
6. Do not add dependencies unless the OSS register is updated and the addition is justified.
7. Keep unrelated cleanup out of the task unless it blocks correctness.
8. Update the execution-plan progress log while working.
